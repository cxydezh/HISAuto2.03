# HISAuto_web 项目总结

## 项目概述
HISAuto_web是一款专为医院住院部设计的HIS（医院信息系统）Agent应用，采用现代化的Web技术栈构建。

## 技术架构
- **后端**: Python + Flask
- **前端**: HTML5 + CSS3 + JavaScript
- **数据**: 硬编码示例数据
- **设计**: 现代化UI，响应式布局

## 功能模块

### 1. 用户认证
- 登录系统（admin/admin）
- 会话管理
- 权限验证

### 2. 工作台
- **左侧面板**: 患者管理
  - Excel文件更新
  - 科室选择（个人、肾病科、呼吸内科、心血管内科）
  - 患者列表（ID、姓名、入院日期）

- **右侧面板**: 信息展示和AI功能
  - 基本信息：患者详细信息
  - AI功能区：AI功能选择和配置
  - AI结果区：运行结果和进度监控

### 3. 设置
- 密码修改功能

## AI功能
1. **智能诊断** - 5个步骤
2. **治疗方案推荐** - 5个步骤
3. **用药安全监测** - 5个步骤
4. **预后评估** - 5个步骤
5. **护理计划制定** - 5个步骤

## 数据结构
- 4个科室
- 11名患者
- 5个AI功能
- 每个AI功能包含5个步骤的工作流程

## 测试结果
- ✅ 功能测试通过
- ✅ 性能测试通过
- ✅ 单元测试通过
- ✅ 数据完整性验证通过

## 部署
1. 安装依赖：`pip install -r requirements.txt`
2. 运行应用：`python start.py`
3. 访问：http://localhost:5000
