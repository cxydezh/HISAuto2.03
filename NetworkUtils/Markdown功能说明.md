# Markdown渲染功能说明

## 功能概述

本次更新为HISAuto_web应用添加了富文本和Markdown格式数据的显示支持。现在运行结果区域可以显示格式化的文本内容，包括标题、列表、表格、代码块等。

## 主要特性

### 1. Markdown语法支持
- **标题**: 支持H1-H6级别的标题
- **文本格式**: 支持粗体、斜体、删除线等
- **列表**: 支持有序和无序列表
- **链接**: 支持超链接
- **图片**: 支持图片显示
- **表格**: 支持数据表格
- **代码**: 支持行内代码和代码块
- **引用**: 支持引用块
- **分割线**: 支持水平分割线

### 2. 代码高亮
- 自动识别编程语言
- 支持多种语言的语法高亮
- 使用GitHub风格的代码主题

### 3. 响应式设计
- 适配不同屏幕尺寸
- 表格支持横向滚动
- 代码块支持横向滚动

## 使用方法

### 在AI结果中显示Markdown内容

当AI功能返回包含Markdown格式的结果时，系统会自动渲染为富文本格式。例如：

```markdown
# 患者诊断报告

## 基本信息
- **患者姓名**: 张三
- **年龄**: 45岁
- **性别**: 男

## 检查结果

| 检查项目 | 结果 | 状态 |
|---------|------|------|
| 血压 | 160/95 mmHg | 异常 |
| 血糖 | 8.2 mmol/L | 异常 |

## 治疗方案
> 建议患者进行低盐、低脂饮食

\`\`\`json
{
  "药物": ["氨氯地平", "缬沙坦"]
}
\`\`\`
```

### 支持的Markdown语法

#### 标题
```markdown
# 一级标题
## 二级标题
### 三级标题
```

#### 文本格式
```markdown
**粗体文本**
*斜体文本*
~~删除线文本~~
```

#### 列表
```markdown
- 无序列表项1
- 无序列表项2

1. 有序列表项1
2. 有序列表项2
```

#### 链接和图片
```markdown
[链接文本](URL)
![图片描述](图片URL)
```

#### 代码
```markdown
`行内代码`

```python
def hello_world():
    print("Hello, World!")
```
```

#### 表格
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据1 | 数据2 | 数据3 |
```

#### 引用
```markdown
> 这是一个引用块
> 可以包含多行内容
```

## 技术实现

### 前端库
- **marked.js**: Markdown解析和渲染
- **highlight.js**: 代码语法高亮

### 样式设计
- 现代化的卡片式设计
- 清晰的层次结构
- 良好的可读性
- 响应式布局

## 注意事项

1. **安全性**: 系统会自动过滤HTML标签，防止XSS攻击
2. **性能**: Markdown渲染在客户端进行，不影响服务器性能
3. **兼容性**: 支持所有现代浏览器
4. **数据格式**: 建议AI返回的结果使用标准Markdown格式
