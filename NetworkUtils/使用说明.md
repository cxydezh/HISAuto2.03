# HISAuto_web 使用说明

## 快速启动

### Windows 用户（推荐）
1. 双击 `start.bat` 文件启动应用
2. 如果遇到端口占用，双击 `cleanup.bat` 清理端口

### 命令行用户
```bash
# 启动应用
python start.py

# 清理端口占用
python cleanup.py
```

## 访问应用
- 地址：http://localhost:5001
- 用户名：admin
- 密码：admin

## 常见问题解决

### 1. 端口5001被占用
**现象**：启动时提示"端口5001已被占用"
**解决**：
- 双击 `cleanup.bat` 自动清理
- 或运行 `python cleanup.py`

### 2. 应用无法启动
**检查**：
- 确保已安装Python 3.8+
- 确保已创建虚拟环境：`python -m venv .venv`
- 确保已安装依赖：`pip install -r requirements.txt`

### 3. 浏览器无法访问
**检查**：
- 确认应用已成功启动
- 检查防火墙设置
- 尝试访问 http://127.0.0.1:5001
