核心函数调用关系
================

前端调用链：
用户选择AI功能 → loadAiWorkflow(functionName) → 
├─ fetch('/api/ai-workflow/{function_name}') → 
│   ├─ renderAiTree(data.workflow) → 
│   │   ├─ 创建tree-item元素
│   │   ├─ 绑定click事件（selectAiTreeItem）
│   │   └─ 添加到ai-tree容器
│   └─ renderAiDescription(data.description)
│
└─ 用户点击tree-item → selectAiTreeItem(item) → 
    ├─ 清除其他选中状态
    ├─ 设置当前选中状态
    └─ 更新描述内容显示

后端调用链：
/api/ai-workflow/{function_name} → 
├─ @login_required 验证登录状态
├─ get_ai_workflow(function_name) [data_display.py]
└─ 返回AI功能配置JSON数据

数据获取函数：
├─ get_ai_workflow(function_name) [data_display.py]
└─ 从AI_FUNCTIONS字典获取指定功能配置

数据流向
========

静态数据 (data_display.py):
├─ AI_FUNCTIONS: AI功能配置字典
├─ 每个功能包含：description, workflow, func_list_id
└─ workflow数组包含多个步骤对象

动态数据 (前端处理):
├─ 用户选择的AI功能名称
├─ 当前选中的tree-item对象
└─ 页面显示状态

数据传递路径:
用户选择AI功能 → API请求 → 后端处理 → 数据返回 → 前端渲染 → 用户点击Item → 显示详细信息

关键数据转换:
├─ AI功能名称 → 完整功能配置
├─ workflow数组 → tree-item列表
└─ tree-item点击 → 详细信息显示

数据更新时机:
├─ AI功能选择时：重新加载整个workflow
└─ tree-item点击时：更新选中状态和描述显示

代码实现细节
============

1. renderAiTree函数:
   - 清空现有tree容器
   - 遍历workflow数组
   - 为每个item创建div元素
   - 绑定click事件监听器
   - 传递完整的item对象

2. selectAiTreeItem函数:
   - 使用querySelectorAll清除选中状态
   - 使用event.target设置当前选中
   - 使用innerHTML更新描述内容
   - 使用模板字符串格式化显示

3. 事件绑定机制:
   - 在renderAiTree时绑定事件
   - 使用箭头函数传递item参数
   - 确保每个item都有独立的事件处理

4. 数据展示格式:
   - 显示item.name作为标题
   - 显示item.description作为描述
   - 显示item.delay作为执行时间
